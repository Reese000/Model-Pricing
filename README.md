## About this project

A reference table of OpenRouter model pricing with a focus on **cache hit discounts** (`input_cache_read` pricing). This project fetches the [OpenRouter models API](https://openrouter.ai/api/v1/models), filters for models that offer cache pricing, and ranks them by cache-read cost per million tokens — making it easy to spot the cheapest cached-inference options for coding and reasoning workloads.

Data is sourced from the public OpenRouter API. The raw API response lives in `openrouter_models_raw.json` (regeneratable), and the filtered cache-pricing subset lives in `openrouter_models_with_cache.json`. This README is auto-generated by `generate_readme.py` — do not edit the table sections by hand.
